用户权限说明
Data Agent 平台有三类用户：超级管理员、Agent 查看用户和 Agent 开发用户。权限分为使用权限、管理权限、发布权限、页面管理权限，分级授权暂不考虑。
角色体系与权限类型
根据产品文档整理为权限说明矩阵，便于评审角色边界。
用户 说明 权限类型 具体说明
超级管理员 Data Agent 平台最高权限用户。 全局管理权限 拥有全部页面管理权限，可查看所有用户创建的 Agent，并管理用户角色。
Agent 查看用户 具有使用特定 Agent 的权限；可在 Agent 配置页按角色、部门、用户配置。 使用权限
  • 使用：可以使用 Agent 进行提问。
  • 分享内容：可以将自己提问的内容、勾选聊天记录进行分享。
  • 分享 Agent：可以将 Agent 链接分享给其他用户。
Agent 开发用户 具有管理后台权限；默认拥有开发相关页面与资源的使用权限。 管理权限
  • 创建：允许在管理系统创建 Agent。
  • 删除：允许删除 Agent。
  • 编辑：允许编辑 Agent 基本设置、skill、知识等内容。
  • 查看：超管可看所有 Agent；普通开发者只能看自己创建或拥有协作权限的 Agent。
Agent 开发用户 以 Agent 为例，skills / 大模型 / 知识库同理。 发布权限 允许发布 Agent；发布时控制全员发布，或指定用户进行发布。
Agent 开发用户 控制是否可进入各后台模块。 页面管理权限 控制是否具有 Agent、skills、大模型、知识库、Agent 管理、Agent 开放集成等页面权限。
Agent 开发用户 次级管理员下发深层权限。 分级授权 暂不考虑。
