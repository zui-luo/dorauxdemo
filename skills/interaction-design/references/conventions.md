# Interaction Conventions

按**触发节点**组织的交互规范。场景明确时直接照做，不需要判断。

## 与原则层的区别

- [example-principles.md](./example-principles.md) — **原则层**：场景模糊时帮你*判断*（如"归属先于可达"）
- 本文件 — **规范层**：场景明确时直接*执行*（如"对象操作完成必出 toast"）

## 收录边界

- ✅ 收：用户能感受到的反馈逻辑（toast / 二次确认 / loading 显示时机 / 错误展示方式）
- ❌ 不收：纯视觉规范（颜色、间距、圆角、字号 → 由 design token 管理）
- 判断标准：这条规范回答的是"**用户会感受到什么反馈**"，而不是"**组件长什么样**"
