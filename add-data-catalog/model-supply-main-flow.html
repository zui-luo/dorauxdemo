Dora 数据中心 × 模型供数

模型供数接入主流程影响图

“指标模型数据集”不是普通表资产。它会把 Dora 的添加流程从“选一个数据”升级为“选一个已治理、带语义约束的供数对象”。

主流程 可复用能力 需要设计拍板 异常 / 风险

1. BI 侧供数对象

来源

模型指标集

由语义模型发布而来，包含数据集、指标、维度、计算字段。

整体可添加 内部资源可查看 继承 BI 权限

数据目录数据集

SQL 数据集、数据库表、发布的自助数据集、Excel 数据集统一进入“数据集”。

前置约束

无权限、未发布、原资产删除、模型关系不满足时，需要在添加前或预览区明确暴露。

→

2. 添加到 Dora 数据中心

入口重构

添加入口分流

建议从“添加数据”进入后，先选“BI 数据目录”，再选数据集 / 模型指标集。

关键设计问题

模型指标集在树中是“可展开但只允许整体勾选”，还是“叶子项 + 右侧详情”？

可复用现有能力

树搜索、多选、已添加禁用、右侧预览、重名校验、添加成功反馈。

拦截点

模型指标转表不支持、权限不足、资产不可用时，不应等到 Agent 使用时才暴露。

→

3. 数据中心管理

工作台升级

从“预览区”变成“资产理解区”

右侧不只看数据，还要看结构、口径、关系、详情、语义信息。

模型指标集详情

整体概览 + 内部数据集 / 指标 / 计算字段详情，需要有清晰切换方式。

Dora 展示规则

添加来源只在导入阶段展示；进入 Dora 后只展示“数据集 / 模型指标集”等数据类型。

删除与失效

Dora 删除、BI 原资产删除、权限变化，需要在树、详情、Agent 配置里保持一致状态。

→

4. Agent / Skill 消费

使用约束

混合数据选择

Excel、数据集、模型指标集、分析主题、仪表板可以混合进入 Agent 数据范围。

按能力筛选

Skill 配置需要展示“支持哪些类型 / 不支持原因”，不能只按目录路径分组。

问数与口径

模型指标集不仅用于取数，还要支持回答指标来源、计算口径、负责人等问题。

使用时异常

会话侧可以保留“提问时提示缺失”，但配置侧必须提前标红和解释。

主流程新增节点

  • BI 数据目录入口
  • 模型指标集整体选择
  • 结构 / 口径 / 关系预览
  • Skill 支持类型判断

需要交互拍板

  • 顶部菜单分流还是弹窗分流
  • 内部资源可展开但不可选的表达方式
  • 详情区用 Tab、侧栏还是二级导航
  • 失效数据是否提供一键清理

当前代码可复用

  • 数据中心树搜索 / 筛选 / 多选
  • 右侧预览容器
  • Agent 数据源分组展示
  • Skill 配置抽屉的数据过滤逻辑

一句话结论

模型供数会让 Dora 主流程从“把 BI 资产添加进来”升级为“把 BI 已治理语义资产添加进来，并在添加、管理、消费三个阶段持续解释它的结构、能力和异常状态”。
