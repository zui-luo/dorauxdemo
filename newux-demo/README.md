# Dora · 合并原型 (Step 1)

这是一个由两个原型合并而来的演示版本：
- **A 文件**（`prototype.html` / 资料联动原型）：提供整体应用骨架（多视图导航、Dora 首页、专家 Agent 列表、资源库、资产选择器等）。
- **B 文件**（`agent-chat-final.html` / Agent 对话原型）：提供会话页里的深度对话体验（执行时间线、流式打字、产出卡片、PPT 预览）。

> 当前是 **Step 1**：结构完成合并、剧本可以跑通，UI 大体延用 A 的风格。
> 下一步 **Step 2** 会把全局 UI 切换到 B 的语言。

## 演示要点

打开后默认进入 **Dora 首页**。可以这样体验：

1. **演示标注**：右上角"交互说明"打开后，页面上的红色编号 1–17 会显示交互说明
2. **顶部方案切换**：默认显示 A 的 Sender 三方案（菜单/平铺/堆叠）；进入会话页后自动切换为 B 的 4 个对话方案（默认/过程前置/产物直出/素色过程）
3. **进会话页**：
   - 点 Dora 首页发送按钮（↑）→ 进 Dora 会话
   - 点专家 Agent 列表里任意一个 Agent → 进对应专家会话
   - 任意进入会话都会自动播放"客户反馈分析 → PPT"剧本（约 43 秒）
4. **重播剧本**：在会话页打开"交互说明"，会出现"▶ 重播剧本"按钮
5. **追加 GenUI**：会话输入框输入"genui"按回车，会追加一条 GenUI 卡片消息
6. **资料面板**：会话页右侧常驻，剧本结束后会有 11 个产出文件；点击任意产出可在面板里预览（PPT 是缩略图列表）
7. **资源库**：rail 第三个入口 → 点资料卡进入详情页 → 右侧 Dora 聊天可收起

## 文件结构

```
newux-demo/
├── index.html      # HTML 结构
├── style.css       # 全部样式
├── script.js       # 视图切换 + 剧本驱动 + 各种交互
└── README.md
```

为什么拆成 3 个文件而不是单个 HTML？合并后总代码量较大，拆开后维护性更好——后续在 `script.js` 里加新交互不会污染到结构和样式。

---

## 关键合并决策

| 项目 | 处理 |
|---|---|
| A 的会话文件抽屉模态 | 删除（被 B 的右侧常驻资料面板替代） |
| A 的 Sender 三方案 | 保留，所有输入框都生效 |
| B 的 4 个对话方案 | 保留，仅会话页显示 |
| 剧本驱动 | 所有 7 个 Agent 进会话都跑同一个客户反馈剧本 |
| CSS class 命名冲突 | B 的对话/资料样式加 `.conv-chat` / `.conv-files` 前缀避免与 A 冲突 |
